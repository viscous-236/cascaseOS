# Geist font files

Geist is distributed under the SIL Open Font License 1.1.

Source: https://github.com/vercel/geist-font

The static 400, 500, 600, and 700 TrueType files were downloaded from the Google Fonts Geist v5 distribution. Self-hosting avoids third-party font requests and makes rendering independent of font CDN availability.

Font stylesheet source: https://fonts.googleapis.com/css2?family=Geist:wght@400;500;600;700&display=swap
